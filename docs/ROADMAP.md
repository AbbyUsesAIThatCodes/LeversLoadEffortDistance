# Roadmap

Authoritative tracker: [Issue #1 — Levers: Load, Effort, and Distance](https://github.com/AbbyUsesAIThatCodes/LeversLoadEffortDistance/issues/1).

1. **Issue #2 — Integrated Core:** first-class apparatus, role-owned masses,
   exact position swaps, movable constrained fulcrum, live math, quantitative
   balance motion, fallback, and focused checks. This version supplies the
   implementation for review; merging its PR completes this step.
2. **Issue #3 — Classroom Release:** prepare and verify the classroom experience
   before calling it lesson-ready. Review and publishing follow the core PR.
3. **Issue #4 — Classroom Virtualization:** integrate the classroom environment
   after classroom readiness. This does not block the first release.

Keep one implementation PR at a time. Distinguish **Issue #N** from **PR #N** in
handoffs and descriptions. Review before merging or deploying; never modify or
deploy the source games as part of this repository's work.

The weighted pointer review retains the development **0.1.0 Integrated Core**
milestone. See [Weighted Pointer Review](WEIGHTED-POINTER.md) and
[Build Identity](BUILD_IDENTITY.md) for behavior, evidence, and generated review
build records. The currently deployed build is independent of PR artifacts.
